Arrow Function:
->Arrow function is used to reduce the syntax of the function
->Arrow function are introduced in the vefsion ES6
->Arrow function follows three rules
  (i) If arrow function contains more than one statement keep in braces {}
  (ii)If arrow function contains return keyword then also keep it in braces {}
  (iii) In arrow functions this keyword works differently(if we are accessing this keyword in arrow function it will be target windows object)
